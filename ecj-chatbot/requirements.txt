# Vector Database & Embeddings
# CVE-2026-45829 (pre-auth RCE, CVSS 10.0) has no patched release, but it is reachable
# only through the ChromaDB *server* REST endpoint. This project embeds ChromaDB via
# PersistentClient (src/embeddings.py) and never starts a server, so the vulnerable
# surface is not exposed. Staying on the 1.x line also avoids the 9 starlette
# advisories that the old 0.5.x floor pulled in. Re-check when a fix ships.
chromadb>=1.5.9
# sentence-transformers CVE-2026-68770 (RCE via trust_remote_code bypass) has no confirmed patched version;
# pin to a recent release. Do not pass trust_remote_code=True in code.
# Floor must be >=5.2.0 so the resolve accepts transformers>=5.5.0 below —
# earlier sentence-transformers releases pin transformers<5.0.0.
sentence-transformers>=5.2.0
# transformers 4.x carries ~25 advisories including RCE. Pinned explicitly because
# sentence-transformers only bounds it upward, not downward.
transformers>=5.5.0
